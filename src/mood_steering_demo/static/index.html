Expression d'humeur d'un petit modèle

Un vecteur est ajouté aux activations du modèle pendant l'inférence (steering) ; on compare le ton obtenu à celui d'un simple prompt de jeu de rôle. La démo montre l'expression d'une humeur dans le texte, rien d'autre.

−1 : pôle négatif (tristesse) · 0 : aucun effet · +1 : pôle positif (joie)
Impulsion : la dose monte de 0 au pic, puis décroît de moitié à chaque demi-vie.
